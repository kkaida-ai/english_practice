# しゃべって英会話（公開版）

日本人向けフリートーク英会話アプリの**公開用バージョン**です。このPCで動かし、Cloudflare の無料トンネルで**公開URL**を発行して、スマホなどどこからでも使えるようにします。**合言葉を知っている人だけ**が使えます。

リポジトリ直下の通常版との違い：

| | 通常版（リポジトリ直下） | 公開版（このディレクトリ） |
|---|---|---|
| 会話AI | Claude Code（個人のサブスクリプション） | **選べる**：Groq の無料 LLM（既定）/ Claude Code / Ollama |
| 声 | ずんだもん・Kokoro・ブラウザ読み上げ | **ずんだもん（VOICEVOX）と Kokoro（リリー・Emma・Ken）のみ** |
| 音声認識 | PC の Whisper / ブラウザ | PC の Whisper → 使えなければ **Groq の Whisper（無料枠）** / ブラウザ |
| 公開 | 同じ Wi-Fi のスマホ（自己署名証明書） | **公開URL**（正式な証明書・どこからでも） |
| 利用制限 | なし | **合言葉ログイン・回数制限・総当たり対策** |

**Claude Pro などの有料プランは不要**です（会話AIは既定で Groq の無料枠を使います。カード登録も不要）。

## 使い方は2通り

| | A. URL で参加する | B. 自分の Mac で動かす |
|---|---|---|
| こんな人に | 管理者から URL と合言葉をもらった人 | 自分で好きな時に使いたい人 |
| インストール | **不要**（スマホ・PC のブラウザだけ） | 必要（下の手順・30分ほど） |
| 使える時間 | 管理者の PC が起動している間だけ | いつでも |
| 必要なもの | Chrome / Safari / Edge、マイク | Apple シリコンの Mac、Groq の無料キー |

### A. URL で参加する（インストール不要）

1. 管理者から **URL（https://〜.trycloudflare.com）** と **合言葉** を受け取る
2. URL をブラウザで開き、合言葉を入力して「はじめる」
3. マイクの使用を許可する（聞かれたら「許可」）
4. マイクボタンを押して英語で話しかける（キーボード入力もできます）

- スマホではホーム画面に追加するとアプリのように使えます（iPhone: 共有 → ホーム画面に追加）
- URL は管理者がアプリを起動し直すたびに変わります。開けなくなったら管理者に新しい URL を聞いてください
- 単語帳・学習記録は使っている端末のブラウザにだけ保存されます

### B. 自分の Mac で動かす

Apple シリコン（M1 以降）の Mac 向けの手順です。ターミナル（アプリケーション → ユーティリティ）で順に実行します。

**1. 道具を入れる**（[Homebrew](https://brew.sh/ja/) が未導入なら先に入れる）

```bash
brew install node python@3.12 ffmpeg cloudflared espeak-ng
```

| もの | 用途 |
|---|---|
| node（20.12 以上） | アプリ本体 |
| python@3.12 | リリーたちの声（Kokoro）と音声認識（Whisper）。Kokoro は Python 3.10〜3.12 で動きます |
| ffmpeg | 音声認識で録音を読み込む（**必須**） |
| cloudflared | 公開URL（`npm run public` のときだけ。Cloudflare のアカウント不要） |
| espeak-ng | 任意：辞書にない単語の発音を補う |

**2. アプリを入手する**

```bash
git clone https://github.com/kkaida-ai/english_practice.git
cd english_practice/public-edition
npm install
```

（git を使わない場合は GitHub の「Code → Download ZIP」で入手して展開し、`public-edition` フォルダに移動）

**3. 声と音声認識のエンジンを入れる**

```bash
python3.12 -m venv .venv
.venv/bin/pip install kokoro soundfile mlx-whisper
```

**4. 会話AI の無料キーを設定する**

1. https://console.groq.com/keys を開き、Google アカウントなどでログイン → 「Create API Key」
2. 表示されたキー（`gsk_` で始まる）をコピー
3. 設定ファイルを作ってキーを書き込む

```bash
cp .env.example .env
open -e .env        # GROQ_API_KEY= の後ろにキーを貼り付けて保存
echo "EIKAIWA_PYTHON=$PWD/.venv/bin/python" >> .env
```

キーは他の人に見せないでください（`.env` は Git に含まれません）。

**5. ずんだもんの声（VOICEVOX）を入れる**

[VOICEVOX 公式サイト](https://voicevox.hiroshiba.jp/)から Mac 版をダウンロードし、`VOICEVOX.app` を「アプリケーション」フォルダに入れます。アプリ起動時に自動で見つけて使います（VOICEVOX を開いておく必要はありません）。

**6. 起動する**

```bash
npm start            # この Mac だけで使う → ブラウザで http://localhost:3000
npm run public       # 公開URL・QRコード・合言葉を表示（スマホや友達も使える）
```

- 初回は音声モデル（約2GB）のダウンロードで数分かかります
- 起動時の表示で「ずんだもん: OK」「Kokoro: OK」「音声認識: OK」を確認してください
- URL は起動するたびに変わります。**この Mac で動かしている間だけ**使えます（止めるには Ctrl+C）

Groq のキーがない場合は PC 内の Ollama で動きますが、**日本語訳やカナ読みの質が大きく下がり、1往復30秒以上かかります**。Groq のキーを設定してください。

## 会話AI の選び方（`.env` の `LLM_PROVIDER`）

| | groq（既定） | claude-code | ollama |
|---|---|---|---|
| 費用 | 無料（カード不要） | この PC の Claude のプラン内 | 無料 |
| 速さ（1往復） | 約2秒 | 約10秒 | 30秒以上 |
| 会話・添削の質 | 良い | 最も良い | 低い（日本語が崩れる） |
| ずんだもんのカナ | 発音辞書から作る | Claude が書く（最も自然） | 発音辞書から作る |
| 回数の上限 | 無料枠：1分8,000トークン（≒1分4回）・1日1,000回。混んだら gpt-oss-20b に自動で切り替え（別枠）| Claude のプランの利用上限 | なし |

- `claude-code` は、この PC にログインしている Claude Code（あなたのアカウント）を使います。合言葉で使う人を限れますが、**あなたのプランを他の人にも使わせる**形になるので、家族や友人など身近な範囲で、Anthropic の利用規約の範囲内で使ってください
- どの LLM でも、このアプリの回数制限（1人あたり・全体）がかかります

### ずんだもんのカナ読みについて（測定結果）

VOICEVOX は日本語の音声合成なので、英語を強勢付きのカナにして読ませています。英語音声認識（Whisper）に聞かせて、英語としての自然さと聞き取りやすさを10文で比べました。

| カナの作り方 | 自然さ（0に近いほど良い） | 聞き間違い |
|---|---|---|
| Claude が強勢付きで書く | **-0.166** | **1.2%** |
| 発音辞書から規則で作る（`tts/en2kana.py`） | -0.244 | 2.4% |
| 強勢なしの素朴なカナ | -0.191 | 4.8% |
| 発音辞書のカナから強勢を外す | -0.416 | 14.5% |

gpt-oss-120b に書かせると単語を飛ばしたり崩したりすることがあり、トークンも1回あたり約400多く使うため、Groq のときは発音辞書から作ります（`ZUNDA_KANA` で変更可）。

## 合言葉

- `.env` に `APP_PASSWORD` がなければ、覚えやすい合言葉（例: `mochi-tiger-1234`）を自動で作り `data/password.txt` に保存します（起動のたびに表示）
- 合言葉を変えると、それまでのログインは全員無効になります
- ログインは30日間有効（ブラウザごと）

## 安全対策

- すべてのページと API は合言葉ログインが必要（トンネル経由のアクセスも例外なし）
- サーバーはこのPCの中（127.0.0.1）だけで待ち受け、外からはトンネル経由でしか届かない
- 合言葉の総当たり対策：1人15分に10回まで、全体で1時間200回まで
- 回数制限（Groq の無料枠を使い切らないため）
  - 1人あたり：会話・単語調べ 1分12回・1日300回、声 1分60回、音声認識 1分15回
  - 全体：会話 1分25回・1日900回（`DAILY_CHAT_LIMIT` で変更可。Groq の無料枠は1日1,000回）
  - Groq が混雑（429）を返したら、数秒待てば空くなら待ってやり直し、そうでなければ予備モデルに切り替え
  - 送る会話履歴は直近8往復まで（トークン節約）
- セキュリティヘッダー（CSP・クリックジャッキング対策など）、ログイン Cookie は HttpOnly / Secure
- AI の応答は項目の欠けや型の違いを補正してから画面に出す（無料モデル対策）

## データの扱い（利用者向けの説明は設定画面にも表示）

- 話した音声はこのPCの Whisper で文字にします（使えないときは Groq に送ります）
- 会話の文章は返答を作るために Groq に送られます
- 単語帳・会話の記録は各利用者のブラウザにだけ保存されます（サーバーには残りません）

## 注意

- ずんだもんの声を使う際は「VOICEVOX:ずんだもん」のクレジット表記が必要です（画面下部に表示）。ずんだもんのイラストは、[東北ずん子・ずんだもんプロジェクトのガイドライン](https://zunko.jp/guideline.html)に沿ってご利用ください
- Kokoro-82M は Apache 2.0 ライセンスです
- Quick Tunnel はお試し用のサービスです（稼働保証なし・URL は毎回変わる）。常設するなら Cloudflare の名前付きトンネル（無料アカウント）や、VPS への設置を検討してください

## 構成

```
server.js            起動・ログイン判定・ルーティング・公開トンネル
lib/llm.js           会話AI（Groq / Claude Code / Ollama）
lib/speech.js        声（VOICEVOX / Kokoro）と音声認識（PC の Whisper / Groq）
lib/security.js      合言葉ログイン・回数制限・セキュリティヘッダー
tts/speech_server.py Kokoro の読み上げ / Whisper の音声認識 / 英語→カナ（PC 内）
tts/en2kana.py       英語 → ずんだもん用の強勢付きカナ（発音辞書から規則で変換）
public/              画面（login.html がログイン画面）
data/                合言葉・セッション用の鍵（自動生成・Git 管理外）
```
